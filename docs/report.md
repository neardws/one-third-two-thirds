# 1/3–2/3 猜想：小规模偏序穷举验证报告

## 方法
- 枚举：nauty `genposetg`（apt 安装的 `nauty-genposetg`），按同构类生成所有 n 元偏序的 Hasse 图（digraph6）。各 n 的总数与 OEIS A000112 完全一致。
- 计算（`delta.c`）：先求传递闭包，再在下集（downset）的位掩码上做 DP。前向 f[D] 表示排好 D 的方式数，后向 g[D] 表示排好补集的方式数，所以 e(P)=f[全集]。
  对不可比对 (x,y)，#{x 在 y 前} = Σ f[D]·g[D∪{x}]，求和范围是满足 x,y∉D 且 D∪{x} 也是下集的 D。全部用 64 位整数精确计数，δ 用 Python `Fraction` 精确约分。
- δ(P)=max_{x,y} min(p_xy, 1−p_xy)，只对非全序计算。
- n=11 用 8 进程并行（genposetg 的 `m i 8` 分片），只输出 δ<0.36 的偏序。

## 观察到的规律
1. **δ=1/3 的刻画（n≤11 内经计算确认）**：δ 恰好等于 1/3 的偏序，全部是若干单点 "1" 和三元例子 T={a<b, c} 的**线性和（ordinal sum）**，且至少含一个 T。反过来，这种形式的偏序也全部出现了。
   - 计数：个数等于“把 n 写成 1 和 3 的有序和的方式数”减 1（扣掉全部是 1、也就是全序的那一种），即 1,2,3,5,8,12,18,27,40，与数据逐项一致。
   - 它们宽度都是 2，都不是不交并（只有 n=3 的 T 本身是），e(P)=3^k，k 是 T 的个数。
   - 这与文献中“δ=1/3 的极端例子都是 T 和链的线性和”的说法吻合。
2. **最接近 1/3 的非极端例子**几乎都是**宽度 2**、线性和意义下不可分解的偏序（加上若干单点的线性和不改变 δ）。最小值依次为 2/5、4/11、5/14、16/45、6/17、37/106，在缓慢逼近 1/3。线性和保持 δ 不变（单点不贡献新的不可比对），所以每个新值都会在 n+1、n+2… 时以 "1+P"、"P+1" 的形式重复出现。
3. 宽度 2 的情形猜想已经被证明（Linial 1984），但从数据看，**宽度 2 恰恰是 δ 最逼近 1/3 的地方**，一般情形的难点不在“宽”的偏序上。宽度 3 的最小例子是 n=8 时的 14/39 ≈ 0.359。
4. δ 的分布见 `delta_hist.png`（n=8,9,10）。随着 n 增大，质量向 1/2 附近集中，靠近 1/3 的例子非常稀少。

## 文件
- `delta.c`：C 程序，计算 e(P) 和最优对（输入为 digraph6）
- `analyze.py`、`run.py`、`show.py`：精确分数、结构分析（宽度、高度、不交并、线性和分解、覆盖关系）和画图
- `results.csv`：n=2..9 每个非全序偏序的 digraph6、e(P)、δ（分数和浮点）、最优对 (x,y)
- `raw_10.csv.gz`：n=10 全部原始结果，列为 n,d6,e,k,x,y，δ=k/e
- `raw_11_filtered.csv`：n=11 中 δ<0.36 的偏序
- `extremes.csv`：每个 n 的 δ=1/3 全部偏序和最小的 10 个 δ>1/3，含结构字段（ordinal_summands 中 T={a<b,c}，[k] 表示 k 元不可分解块，covers 为覆盖关系 i<j）
- `delta_hist.png`：δ 分布直方图
