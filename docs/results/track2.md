# Track 2：一般下界 / 特殊类 —— 文献精读与可攻路线（2026-10-15）

核实说明：标【已读】的来源是我读过 arXiv 全文或摘要页的；标【转引】的只核对了 ACPP 2026 的参考文献条目，原文没读；标【未核实】的是记忆中的结论，引用前必须查原文。

## 0. 先说结论
- 现在最好的一般下界是 BFT 常数 C_BFT=(5−√5)/10≈0.276393 再加一个 ε。这个 ε=3^{-3^{16·10^18}}，小到微不足道【已读 ACPP arXiv:2609.30888, Thm 1.2, (1.5)】。
- **ACPP 之后，1/3–2/3 猜想还没解决的部分只剩“宽度有界、且 range（与单个元素不可比的元素个数的最大值）有界”的偏序**：
  - 宽度 > K 的偏序，ACPP Thm 1.4 证明了 δ ≥ e^{-1} − o(1) > 1/3；
  - 宽度 < K 且 range 足够大的偏序，Aires–Kahn arXiv:2510.26134 证明了 δ → 1/2【已读】。
  - 问题是 K 和 L(K) 都不显式。所以“D-thin 偏序”（range ≤ D）正是开放的核心区域：D ≤ 5 由 Brightwell–Wright 1992 解决，D = 6 由 Peczarski 2008 解决，D ≥ 7 还开放。ACPP 原话是“their methods break down for larger D”【已读 ACPP §1.3】。
- **推荐的主攻方向：用“窗口/转移矩阵 + 精确证书”证明 7-thin 偏序满足 1/3–2/3。** 它和我们在 α 族上跑通的整套工具（转移矩阵、精确有理证书、Lean）直接衔接。n=15 全枚举作为并行的纯算力任务。

## 1. 三篇核心证明的架构与瓶颈

### 1.1 Kahn–Saks 1984（3/11）【转引：Order 1 (1984) 113–126；架构按 ACPP §2.1 与 CPP 2104.09009 的复述】
- 平均高度 h(x)=E[f(x)]。存在不可比的 x, y 满足 h(x) ≤ h(y) ≤ h(x)+1，因为一定有两个不可比元素的平均高度差 ≤ 1。
- 核心工具是 Kahn–Saks 不等式：F(k) = #{L : L(y)−L(x)=k} 关于 k 对数凹。证明靠 Stanley 的 Alexandrov–Fenchel 方法（混合体积）。
- 只用“对数凹 + 平均差 ≤ 1”这两条，最优就只能推出 3/11。瓶颈在：一维对数凹序列满足均值约束时最坏的分布。

### 1.2 Brightwell–Felsner–Trotter 1995（(5−√5)/10）【转引：Order 12 (1995) 327–349；细节按 ACPP §2 已读】
- 改看 **BFT 三元组** (x, y, z)：三者不构成链，且 h(x) ≤ h(y) ≤ h(z) ≤ h(x)+2。
- 按可比关系分四种情形 A–D：
  - A、B 两种情形可直接推出 ≥ 1/3；
  - C（三者两两不可比）推出 > 0.2764，ACPP 附录 A 指出这个论证其实给出 67/242 ≈ 0.27686；
  - **D（x≺z，x∥y，y∥z）是瓶颈。**
- 情形 D 的变量：p(i,j)=P[f(y)−f(x)=i, f(z)−f(y)=j]，a1=p(1,1)，a2=p(1,2)+p(2,1)，a3=p(2,2)，S=p+p′。用到的不等式是 (2.1) 2a1+a2 ≤ S，2a2+2a3 ≤ S，7 ≤ 9S+7a1+3a2+3a3，以及 (2.2) **4a1·a3 ≤ a2²**。最后这条是 cross-product 不等式的 k=ℓ=1 特例，BFT 用 Ahlswede–Daykin 四函数定理证明。
- **障碍一（无穷屏障）：** 无穷 Fibonacci 偏序 F（x_i ≺ x_j 当且仅当 j−i ≥ 2，range 为 2）上 δ(F)=C_BFT，等号成立【已读 ACPP §1.3，原始出处 BFT §7、Brightwell 1988】。上面所有不等式对无穷偏序同样成立，所以**任何只用局部概率不等式的论证都会卡在 C_BFT**，要突破必须用到“有限”这一点。
- **障碍二：** 一般的 cross-product 猜想（BFT Conj 3.1）仍然开放。宽度 2 的情形已由 Chan–Pak–Panova 证明，并推广到广义 CPC 和 q-类比【已读 arXiv:2104.09009, TAMS 2022】。CPP 还指出，广义 CPC 能同时推出 Kahn–Saks、GYY 和 XYZ 三个不等式。但按障碍一，即使完整的 CPC 成立，也越不过 C_BFT。

### 1.3 Aires–Chan–Pak–Panova 2026（C_BFT+ε）【已读 arXiv:2609.30888】
按偏序分三类处理：
1. **range 小（π(P) ≤ D），Thm 1.3：** δ > C_BFT + η_D，η_D=(D+1)^{-4(D+1)}/4096。做法是更仔细地挑 BFT 三元组，在情形 D 里用 R := S−2a1−a2 的下界（Lemma 2.4），并利用有限性：有限 Fibonacci 偏序端点附近的那些对平衡度 ≥ 1/3。
2. **宽度大（w > K），Thm 1.4：** δ ≥ e^{-1}−o(1)，靠 canopy 反链、Aires–Kahn 的窗口估计（arXiv:2509.11549【已读】）、XYZ 不等式和 Haqi–Kahn ideal 不等式（arXiv:2608.12678）。e^{-1} 来自 Grünbaum 不等式。
3. **宽度小、range 大，Thm 1.5 = Aires–Kahn arXiv:2510.26134 Thm 1.6：** δ → 1/2。

ε 小到天文数字，原因是第 2、3 类里的 K 和 L 都不显式，而第 1 类的 η_D 随 D 超指数衰减。作者在 §7.4 写道，希望有人能把下界提高 0.001 左右，但“new tools and fresh ideas are needed”。

**瓶颈的精确位置：** 中等 range、宽度有界的有限偏序，在 BFT 情形 D 里怎样定量利用“有限”。Fibonacci 型的长链状局部结构就是极值的样子。

**最接近能拿下的开放类：**
1. **7-thin（以及 D-thin，D ≥ 7）。** 按 §0 的分析，这本质上就是剩下的全部难点（再加上宽度有界）。
2. **宽度 3。** Kahn–Saks 猜想过宽度 ≥ 3 时 δ > 1/3，至今开放。
3. 区间序（半序已解决）、2 维偏序、高度 2（取决于 TGF92 的实际范围）。这几类目前的状态都是【未核实】，没有在 2025–26 年的文献里看到被解决，要逐一去查 Chan–Pak 综述 arXiv:2311.02743 的 §11。

## 3. 排序后的具体攻法（都带计算部分）

### 攻法 1（推荐）：7-thin 偏序的 1/3–2/3，用转移矩阵加精确证书
- 思路：range ≤ D 时，按平均高度排序后，每个元素只和前后有界个元素不可比，偏序是“带状”的。于是线性扩张计数可以写成有限状态转移矩阵的乘积，和我们的 α 族一模一样，可以按局部窗口类型枚举。
- 目标是证明：对每种局部窗口类型，存在一对平衡度 ≥ 1/3 的元素。困难在于概率不是局部量：P[x<y] 依赖整个偏序。处理办法是给转移矩阵的“边界向量”取一个锥/区间包络，对任意外部上下文都给出有理区间界。这正是 Codex 第二步用过的“区间迭代 + 不变锥”技术。
- 第一步要做的，是先读 Brightwell–Wright 1992 和 Peczarski 2008 的原文，看他们具体卡在哪：是情形数爆炸，还是局部论证本身失效。ACPP 只说了“break down”。
- 计算部分：
  1. 枚举所有 7-thin 的不可分解局部窗口；
  2. 精确 DP；
  3. 用 LP/区间方法给出与上下文无关的界；
  4. 输出证书，再在 Lean 里核对。
- 可行性：中到偏难。如果局部方法可行，估计 1–3 个月，有可能写成论文；也可能发现某些窗口和上下文有关、无法局部化，这本身也是有价值的结论。拿 D = 6 复现 Peczarski 是很好的第一个里程碑，约 2 周。

### 攻法 2：n = 15 全部偏序的穷举验证（纯算力，把 Gupta 的 n ≤ 14 往前推一步）
- 规模：n = 14 约有 1.1×10^9 个非同构偏序，n = 15 约 3.4×10^10 个（OEIS A000112，数值是凭记忆写的，【需核对】）。
- 剪枝办法：
  - 有孪生元素（上下集完全相同）时 δ = 1/2，直接跳过；
  - 线性和（ordinal sum）可以化归到分量；
  - 先算若干候选对（平均高度相近的对）的概率，一旦有一对 ≥ 1/3 就提前停。
- 生成器用 nauty genposetg 按 res/mod 分片。我们已有的 delta.c 只需加上提前退出。
- 估计每个偏序平均约 10 μs 到 0.1 ms，总计约 10^5–10^6 CPU·小时，放在 Mac mini 上太慢，需要集群或云。可以先实测 n = 13、14 的吞吐量再定。
- 可行性：技术上确定能做完，产出一个“n ≤ 15”的结果。理论价值有限，但顺带能得到 n = 15 时 δ 的最小值和极值结构，可以检验极值是否总是梯子型。

### 攻法 3：BFT 情形 D 的“不等式天花板”计算
- 把情形 D 写成关于 3×3（或更大截断的）分布 p(i,j) 的优化问题。约束可以逐步加入：
  - BFT 的 (2.1)–(2.2)；
  - 完整的（广义）CPC，宽度 2 已证，一般情形是猜想；
  - Kahn–Saks 对数凹；
  - 由 XYZ 和 GYY 推出的约束。
- 再用 LP/SDP 或多项式优化求每组约束下 max δ 的下确界。
- 预期结果：只要约束对无穷 Fibonacci 偏序都成立，下确界就是 C_BFT（障碍一）。所以这个实验的真正用处是两件事：
  1. 精确量化“有限性”需要贡献多少；
  2. 找出哪一种额外的有限偏序约束（例如 R 的下界、边界效应）能把天花板推高，比如到 0.277–0.28。
- 可行性：容易，1–2 周。但单靠它推不出新定理，只是为攻法 1 和理论工作提供方向。
